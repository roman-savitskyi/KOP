REACT CONTEXT

Вбудований механізм глобального стану

CREATECONTEXT

Створення контексту

import { createContext } from 'react';

const ThemeContext = createContext({
  theme: 'light',
  toggleTheme: () => {}
});

PROVIDER

Надання значення контексту

const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const value = {
    theme,
    toggleTheme: () => setTheme(
      prev => prev === 'light' ? 'dark' : 'light'
    )
  };

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
};

USECONTEXT

Споживання контексту в компоненті

import { useContext } from 'react';

const ThemedButton = () => {
  const { theme, toggleTheme } = useContext(ThemeContext);

  return <button onClick={toggleTheme}>{theme}</button>;
};

CONTEXT ОБМЕЖЕННЯ

  • Re-render всіх споживачів при зміні
  • Немає вбудованого кешування
  • Складна оптимізація
  • Немає DevTools

КОЛИ ПОТРІБЕН STATE MANAGER?

  • Складна бізнес-логіка
  • Часті оновлення стану
  • Потреба в DevTools та time-travel
  • Серверний стан (caching, sync)

STATE MANAGERS

Огляд популярних рішень

REDUX TOOLKIT

Офіційний стандарт для Redux

REDUX TOOLKIT

  • Flux архітектура
  • Single source of truth
  • Immutable updates (Immer)
  • Redux DevTools
  • RTK Query для API

REDUX TOOLKIT

createSlice

import { createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: state => {
      state.value += 1; // Immer дозволяє мутації
    },
    decrement: state => {
      state.value -= 1;
    },
    incrementByAmount: (state, action) => {
      state.value += action.payload;
    }
  }
});

REDUX TOOLKIT

configureStore

import { configureStore } from '@reduxjs/toolkit';

const store = configureStore({
  reducer: {
    counter: counterSlice.reducer
  }
});

REDUX TOOLKIT

React hooks

import { useSelector, useDispatch } from 'react-redux';

const Counter = () => {
  const count = useSelector(state => state.counter.value);
  const dispatch = useDispatch();

  return (
    <button onClick={() => dispatch(increment())}>
      {count}
    </button>
  );
};

REDUX ПРИНЦИПИ

  • Single Source of Truth - один store
  • State is Read-Only - тільки через actions
  • Changes via Pure Functions - reducers
  • Predictable State Updates

MIDDLEWARE

Розширення функціональності між action та reducer

MIDDLEWARE FLOW


Action → Middleware 1 → Middleware 2 → Reducer → Store

                ↓ Side Effects ↓
            - Logging
            - Async API calls
            - Analytics
            - Crash reporting

REDUX THUNK

Middleware для async логіки

// Action Creator повертає функцію
const fetchUser = (userId) => {
  return async (dispatch, getState) => {

    dispatch({ type: 'USER_LOADING' });

    try {
      const response = await fetch(`/api/users/${userId}`);
      const data = await response.json();
      dispatch({ type: 'USER_SUCCESS', payload: data });
    } catch (error) {
      dispatch({ type: 'USER_ERROR', payload: error });
    }
  };
};

CUSTOM MIDDLEWARE

Власний middleware

const logger = store => next => action => {
  console.log('Dispatching:', action);
  const result = next(action);
  console.log('Next State:', store.getState());
  return result;
};

const store = configureStore({
  reducer: rootReducer,

ПРОСТИЙ SELECTOR

RESELECT

Мемоізовані селектори

import { createSelector } from '@reduxjs/toolkit';

const selectTodos = state => state.todos;
const selectFilter = state => state.filter;

const selectFilteredTodos = createSelector(
  [selectTodos, selectFilter],
  (todos, filter) => {
    return todos.filter(todo => todo.status === filter);
  }
);

RESELECT ПЕРЕВАГИ

  • Мемоізація результатів
  • Re-compute тільки при зміні inputs
  • Композиція селекторів
  • Запобігання зайвим re-renders

ZUSTAND

Мінімалістичний state manager

ZUSTAND

  • Простий API (один hook)
  • Малий розмір (~1KB)
  • Без boilerplate
  • Працює поза React
  • Підтримує middleware

ZUSTAND

Створення store

import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increment: () => set(state => ({
    count: state.count + 1
  })),
  decrement: () => set(state => ({
    count: state.count - 1
  })),
  reset: () => set({ count: 0 })
}));

ZUSTAND

Використання в компоненті

const Counter = () => {
  const { count, increment, decrement } = useStore();

  return (
    <div>
      <span>{count}</span>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
    </div>
  );
};

MOBX

Reactive state management

MOBX

  • Observable state
  • Автоматичне відстеження залежностей
  • Мутабельний підхід
  • Computed values
  • Actions для змін

MOBX

Створення store

import { makeAutoObservable } from 'mobx';

class CounterStore {
  count = 0;

  constructor() {
    makeAutoObservable(this);
  }

  increment() {
    this.count += 1;
  }

  decrement() {
    this.count -= 1;
  }
}

const counterStore = new CounterStore();

MOBX

Observer компонент

import { observer } from 'mobx-react-lite';

const Counter = observer(() => (
  <div>
    <span>{counterStore.count}</span>
    <button onClick={() => counterStore.increment()}>
      +
    </button>
  </div>
));

RECOIL

Атомарний state manager від Meta

RECOIL

  • Atoms - одиниці стану
  • Selectors - derived state
  • React-first підхід
  • Concurrent Mode support
  • Experimental від Meta

RECOIL

Atom

import { atom, selector } from 'recoil';

const countState = atom({
  key: 'countState',
  default: 0
});

const doubledCount = selector({
  key: 'doubledCount',
  get: ({ get }) => get(countState) * 2
});

RECOIL

Hooks

import { useRecoilState, useRecoilValue } from 'recoil';

const Counter = () => {
  const [count, setCount] = useRecoilState(countState);
  const doubled = useRecoilValue(doubledCount);

  return (
    <button onClick={() => setCount(c => c + 1)}>
      {count} (doubled: {doubled})
    </button>
  );
};

VUE STATE MANAGERS

VueX та Pinia

VUEX

  • Офіційний state manager для Vue 2/3
  • Flux-подібна архітектура
  • State, Mutations, Actions, Getters
  • Modules для масштабування

VUEX

Store

import { createStore } from 'vuex';

const store = createStore({
  state: {
    count: 0
  },
  mutations: {
    increment(state) {
      state.count++;
    }
  },
  actions: {
    incrementAsync({ commit }) {
      setTimeout(() => commit('increment'), 1000);
    }
  }
});

PINIA

Новий стандарт для Vue 3

PINIA

  • Простіший API ніж VueX
  • TypeScript підтримка
  • Без mutations (тільки actions)
  • DevTools інтеграція
  • Модульна архітектура

PINIA

defineStore

import { defineStore } from 'pinia';

export const useCounterStore = defineStore('counter', {
  state: () => ({ count: 0 }),
  getters: {
    doubled: (state) => state.count * 2
  },
  actions: {
    increment() {
      this.count++;
    },
    async incrementAsync() {
      await delay(1000);
      this.count++;
    }
  }
});

JOTAI

Примітивний та гнучкий state manager

  • Атомарний підхід (як Recoil)
  • Мінімалістичний API
  • Bottom-up підхід
  • TypeScript-first

JOTAI

Приклад

import { atom, useAtom } from 'jotai';

const countAtom = atom(0);

const Counter = () => {
  const [count, setCount] = useAtom(countAtom);
  return <button onClick={() => setCount(c => c + 1)}>{count}</button>;
};
