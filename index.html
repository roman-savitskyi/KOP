КОМПОНЕНТИ: ІНКАПСУЛЯЦІЯ

import { useState } from 'react';

export function Price(props) {
  const { price } = props;
  const [color, setColor] = useState('yellow');

  const style = { backgroundColor: color };

  const changeColor = () => {
    const randomColor = `#${Math.floor(Math.random() * 16777215).toString(16)}`;
    setColor(randomColor);
  };

  return (
    <div style={style}>
      {price}
    </div>
  );
}

ВНУТРІШНІЙ СТАН

  • Лише стан (state) спричиняє ре-рендер
  • State має використовуватись під час рендеру сторінки
  • Props не змінюється, на відміну від state

ЯК СТВОРИТИ КОМПОНЕНТ ЗІ СТАНОМ

import { useState } from 'react';

export function Price(props) {
  const { price } = props;
  const [color, setColor] = useState('yellow');

  const changeColor = () => {
    const randomColor = `#${Math.floor(Math.random() * 16777215).toString(16)}`;
    setColor(randomColor);
  };

  return (
    <div style={{ backgroundColor: color }}>
      {price}
      <button onClick={changeColor}>Change color {color}</button>
    </div>
  );
}

USESTATE: СИГНАТУРА ТА ЗМІНА СТАНУ

// створення стану
const [state, setState] = useState(initialValue);

// переприсвоєння стану — лише через сеттер
setState(newValue);              // нове значення
setState(prev => prev + 1);      // на основі попереднього
  • state — поточне значення, setState — сеттер
  • useState(initialValue) — початкове значення (лише 1-й рендер)
  • Пряме state = ... не працює — тільки сеттер планує ре-рендер

USESTATE: ПОЧАТКОВЕ ЗНАЧЕННЯ ЯК ФУНКЦІЯ

// звичайне початкове значення
const [color, setColor] = useState('yellow');

// ліниве обчислення — функція виконається лише на 1-му рендері
const [color, setColor] = useState(() => getInitialColor());

// ❌ так функція викликається на КОЖНОМУ рендері
const [color, setColor] = useState(getInitialColor());
  • Передаємо функцію, а не її виклик
  • React викличе її лише один раз — при монтуванні
  • Корисно для дорогих початкових обчислень

ОСОБЛИВОСТІ STATE

  • Не потрібно присвоювати значення напряму
  • Не потрібно змінювати стан в асинхронних функціях
  • React групує виклики setState (batching)

ОСОБЛИВОСТІ STATE: BATCHING

const changeColor = () => {
  const randomColor = `#${Math.floor(Math.random() * 16777215).toString(16)}`;
  setColor(randomColor);
  setColor(randomColor); // React згрупує це в один ре-рендер
};

ЯК ПЕРЕДАТИ ДАНІ ДО КОМПОНЕНТА?

ПОТІК ПОДІЙ (PROPS / EVENTS)

  • Capture Phase (1) — від Window вниз до цілі
  • Target Phase (2) — сам елемент-ціль
  • Bubbling Phase (3) — від цілі вгору до Window

ОСОБЛИВОСТІ PROPS

  • Лише для читання (read-only)
  • Працюють як чисті функції

ЯК ПЕРЕДАТИ PROPS

  • За допомогою атрибутів
  • Як вкладені компоненти
  • Строка, число, булеве, масив, об'єкт, функція, інший JSX-елемент

PROPS.CHILDREN

export function Title(props) {
  const { tag } = props;

  return (
    <>
      {tag === 'h1'
        ? <h1>{props.children}</h1>
        : <p>{props.children}</p>}
    </>
  );
}
