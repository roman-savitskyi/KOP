РЕНДЕРИНГ

  • DOM (Document Object Model)
  • DOM-документ є деревом
  • Гілки дерева оновлюються повністю

VIRTUAL DOM

  • React-DOM працює з віртуальним DOM
  • Віртуальний DOM зберігається в памʼяті і синхронізується з DOM
  • Процес узгодження (reconciliation)

ЯК РЕАКТ ВИКОРИСТОВУЄ VIRTUAL DOM?

  • React спостерігає (Observer) за станами компонентів
  • При зміні стану компонента оновлює VDOM
  • Порівняння VDOM з попередньою версією (diffing)
  • Оновлення переносяться в реальний DOM пакетно (batch)

REACT FIBER

  • React використовує React Fiber як механізм узгодження

КОМПОНЕНТИ

  • Найменша атомарна одиниця в React
  • Розроблені для повторного використання
  • Містять props, які приймають дані через параметри
  • Описуються станом state, що зберігає дані властивостей
  • Містять props & state
  • Функціональні та класові компоненти
